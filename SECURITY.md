# Security policy

This repository contains security-control templates, not tenant secrets or incident evidence.

Report a suspected vulnerability privately through GitHub private vulnerability reporting when it is enabled. Otherwise use Shoothill's established service-desk or security-escalation channel and identify this repository. Do not open a public issue containing exploit details, tenant identifiers, sign-in logs, tokens, credentials, IP inventories, or customer evidence.

Include the affected policy or tool, the unsafe outcome, reproduction conditions, relevant Microsoft documentation, and whether the issue can cause lockout, bypass, token replay, or unintended access. Do not test against a production tenant without explicit authorization.

All policy corrections must remain Report-only until the documented readiness gate and acceptance tests pass in the target tenant.
